# 前台 v0.1 开发范围

## 目标

交付一个可自托管的单用户 Web 应用，让用户可以：

1. 首次创建唯一管理员；
2. 登录；
3. 在首页选择工作或个人空间；
4. 用自然语言快速记录；
5. 在对应空间查看日记时间流与待整理收件箱；
6. 把待整理记录收入日记或放回收件箱；
7. 删除不再需要的记录。

## 产品原则

- 记录时只安静收下，不立即分析；
- 工作和个人完全隔离；
- 首页不展示两个空间的具体内容；
- 不打卡、不评分、不判断失败；
- 手机和电脑功能一致；
- 原始内容始终保留。

## 明确不做

- AI；
- 目标管理；
- 里程碑与下一步；
- Web Push；
- 多用户注册；
- 社交与协作；
- 日历、积分和排行榜。

## 验收场景

用户用手机打开网站，完成首次初始化并登录。用户输入一段文字、选择“个人”并保存。进入个人空间可以看到该记录，进入工作空间完全看不到。用户可以把记录收入日记，也可以删除。
